NBA EDGE v2 — MOBILE + DESKTOP RESEARCH OPTIMIZER

RUN LOCALLY: Open index.html on a computer. CSV import and optimizer work.

RUN ON IPHONE / ANDROID: Host these files on HTTPS. Suggested: Create a free GitHub repository, upload all files in this folder at repository root, then Settings > Pages > Deploy from branch > main/root. Wait for the published URL, open on iPhone Safari, Share > Add to Home Screen.

DATA: Demo data is NOT real NBA data. Use Download CSV Template, fill real slate data, then import. Or enter a CORS-enabled HTTPS CSV feed URL and refresh. Automatic refresh every five minutes operates ONLY while the page remains active. It does not include a background server or a paid API. Do not paste API keys into this app or commit them to GitHub.

OWNERSHIP: Values are supplied by the CSV. Missing ownership defaults to zero, NOT an estimated real-world ownership number. Backtesting and a validated estimation model are not yet implemented.

OPTIMIZATION: Beam search heuristic; not guaranteed globally optimal. No wagers, entries, or deposits supported.
